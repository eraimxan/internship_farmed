Изменение правил поиска по полям даты:

Ранее поиск по датам С … ПО осуществлялся указанием в поиске 2-х полей crdate_from и crdate_to.

Теперь поиск по датам осуществляется по принципу поиска по массиву значений.

Примеры:

{crdate: “2019-10-01”} - поиск по дате crdate С 2019-10-01

{crdate: [“2019-10-01”]} - поиск по дате crdate С 2019-10-01

{crdate: [“2019-10-01”, “2019-10-24”]} - поиск по дате crdate С 2019-10-01 ПО 2019-10-24

{crdate: [“”, “2019-10-24”]} - поиск по дате crdate ПО 2019-10-24

Изменение правил поиска по текстовым полям:

Ранее поиск по текстовым поля работал только с точным совпадением.

Теперь в поиске можно использовать специальные символы * и ?

Примеры:

{nameRU: “уголь”} - Поиск по точному значению в поле nameRu (nameRu = ‘уголь’)

{nameRU: “?уголь”} - Поиск по части слова без учета морфологии в поле nameRu (nameRu = ‘* уголь *‘)

{nameRU: “?уголь*“} - Поиск по части слова без учета морфологии только после текущего слова или фразы в поле nameRu (nameRu = ‘уголь *‘)

{nameRU: “*уголь”} - Поиск с учетом морфологии в поле nameRu (nameRu math(‘уголь’))
