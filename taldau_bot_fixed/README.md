# Taldau Bot — Инвестиции в основной капитал Казахстана

Telegram-бот для автоматического парсинга, обновления и выгрузки данных с [taldau.stat.gov.kz](https://taldau.stat.gov.kz/ru/NewIndex/GetIndex/701830).

**Поддерживает:**
- 📅 Помесячные данные (нарастающим итогом: Янв, Янв-Фев, ...)
- 📆 Годовые данные (2019, 2020, 2021, ...)
- Автоматическое обнаружение и загрузку новых периодов
- Инкрементальное обновление (старые данные не перезаписываются)
- Экспорт в Excel с навигацией и иерархией

## Установка и запуск

### 1. Требования
- Python 3.10+
- pip

### 2. Установка зависимостей

```bash
cd taldau_bot
pip install -r requirements.txt
```

### 3. Создание бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. Команда `/newbot` → введи имя и username
3. Скопируй токен вида `7581885889:AAE1JZVl...`

### 4. Запуск

**Способ 1 — через переменную окружения (рекомендуется):**
```bash
BOT_TOKEN=<твой_токен> python main.py
```

**Способ 2 — вставить токен в код:**
В файле `config/settings.py` замени:
```python
BOT_TOKEN: str = os.getenv("BOT_TOKEN", "YOUR_BOT_TOKEN_HERE")
```
на:
```python
BOT_TOKEN: str = "7581885889:AAE1JZVl..."
```

### 5. Запуск в фоне (Linux/сервер)

```bash
# С nohup
nohup BOT_TOKEN=<токен> python main.py > /dev/null 2>&1 &

# Или через screen
screen -S taldau_bot
BOT_TOKEN=<токен> python main.py
# Ctrl+A, D — отсоединиться от screen
```

## Первый запуск: импорт существующих данных

Если у тебя уже есть файлы `ALL_KAZAKHSTAN_FULL.csv` и `MONTHLY_FINAL.csv`:

1. Положи оба файла **в папку `taldau_bot/`** (рядом с `main.py`)
2. В боте нажми **📤 Импорт CSV (первый раз)**
3. Нажми **✅ Файлы готовы — импортировать**
4. Бот создаст `data/master.csv` и запомнит загруженные периоды

После этого при обновлении бот будет **только дописывать новые данные**, не трогая старые.

## Как получить Cookie

Cookie нужен для авторизации на сайте taldau.stat.gov.kz.

1. Открой в браузере: https://taldau.stat.gov.kz/ru/NewIndex/GetIndex/701830
2. Нажми **F12** → перейди на вкладку **Network**
3. Обнови страницу (F5)
4. Найди запрос `GetIndexTreeData` в списке
5. Открой вкладку **Headers** → найди строку **Cookie:**
6. Скопируй всё значение после `Cookie:` (длинная строка)
7. Отправь боту через команду `/setcookie`

Cookie действует несколько часов. При ошибке "сессия недействительна" — обнови Cookie.

## Принцип работы с данными

- **`data/master.csv`** — главная база: строки = районы/показатели, колонки = периоды
- При обновлении **новые колонки дописываются**, старые данные **не трогаются**
- Пустые ячейки в существующих строках **заполняются** новыми данными
- Непустые ячейки **никогда не перезаписываются**
- Новые строки (если появились новые районы) **добавляются в конец**
- Excel строится из мастера при каждом обновлении — содержит **все периоды**

### Формат колонок периодов:
- **Годовые:** `y122023` = 2023 год (PERIOD_ID=7 на сайте)
- **Месячные:** `y032024` = январь–март 2024, нарастающим итогом (PERIOD_ID=8)
- **Месяц 12** автоматически определяется как годовой итог

### Разница между годовыми и месячными запросами:
- **Месячные** (PERIOD_ID=8): сайт возвращает данные нарастающим итогом с начала года
- **Годовые** (PERIOD_ID=7): сайт возвращает итоги за полный год

## Настройка systemd (для запуска как сервиса)

Создай файл `/etc/systemd/system/taldau_bot.service`:

```ini
[Unit]
Description=Taldau Telegram Bot
After=network.target

[Service]
Type=simple
User=<твой_пользователь>
WorkingDirectory=/path/to/taldau_bot
Environment=BOT_TOKEN=<твой_токен>
ExecStart=/usr/bin/python3 main.py
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable taldau_bot
sudo systemctl start taldau_bot
sudo systemctl status taldau_bot
```

## Исправления и улучшения (v2.1)

1. **Поддержка годовых данных** — добавлена кнопка "📆 Загрузить годовые" с выбором конкретных лет
2. **Автоматическое определение YEAR_MAP** — годовые колонки больше не захардкожены, определяются динамически
3. **Правильные метки декабря** — `y122025` теперь показывается как "2025 (год)" вместо "Янв-Дек 2025"
4. **Защита данных при merge** — непустые ячейки больше не перезаписываются
5. **Исправлены пути импорта CSV** — теперь ищутся от BASE_DIR, не от рабочей директории
6. **Проверка размера файла** — перед отправкой в Telegram проверяется лимит 50 МБ
7. **Валидация периодов** — `period_key()` теперь проверяет корректность месяца и года
8. **Проверка обоих типов данных** — при проверке сессии показываются и месячные, и годовые периоды
