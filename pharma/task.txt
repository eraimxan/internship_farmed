Доступ к API
Доступ к объектам НСИ через программный интерфейс API предоставляется неавторизованным пользователям.

Для реализации информационного взаимодействия необходимо выполнять HTTP-запросы на URL сервиса:

https://nsi.eaeunion.org/api/v1/{endPoint}[?params]
где:
https://nsi.eaeunion.org – адрес Портала ЕС НСИ;
/api – адрес интерфейса;
/v1 – версия API, на текущий момент актуальная первая версия (v1);
/{endPoints} - наименования вызываемых методов;
?params - параметры, указываемые для соответствующего метода (при наличии).
За один запрос можно получить не более 1500 элементов, при необходимости получения меньшего количества элементов или получения элементов с определенной позиции, необходимо использовать параметры (limit и offset).

бщие сведения
Доступ к объектам НСИ через программный интерфейс API предоставляется неавторизованным пользователям.

Для реализации информационного взаимодействия необходимо выполнять HTTP-запросы на URL сервиса:

https://nsi.eaeunion.org/api/v1/{endPoint}[?params]
где:
https://nsi.eaeunion.org – адрес Портала ЕС НСИ;
/api – адрес интерфейса;
/v1 – версия API, на текущий момент актуальная первая версия (v1);
/{endPoints} - наименования вызываемых методов;
?params - параметры, указываемые для соответствующего метода (при наличии).
Коды состояний
В ответ на запросы клиента, сервер может возвращать коды статусов, описанные в таблице:

Код статуса	Состояние	Описание
200	OK	Возвращается клиенту в случае успешного выполнения запроса
400	Bad Request	Возвращается в случае ошибки на стороне клиента. В качестве ошибок может быть как неправильный синтаксис запроса, так и неверные параметры запроса
404	Not found	Возвращается клиенту, когда REST-API не может сопоставить URL клиента с ресурсом
413	Request Entity Too Large	Возвращается клиенту, если он послал запрос с превышением максимального лимита, например, запросил больше 1000 записей из объекта НСИ
500	Internal Server Error	Отправляется, когда сервер, по какой-то причине, не может обработать запрос клиента
Ограничение результата
Для ограничения (фильтрации) выдаваемого результата указываются значения в блоке входных параметров conditions:

offset - в параметре задается значение cмещения, с которого следует возвращать блок данных;
limit - в параметре указывается количество записей, возвращаемых за один запрос. Максимальное значение limit = 1500. В случае превышения максимально разрешенного сервером значения будет возвращена ошибка 413.
При получении результата будут возвращены те же параметры в блоке pagination.

Фильтрация
Для ограничения (фильтрации) выдаваемого результата указываются значения в блоке входных параметров conditions:

conditionType - тип соответствия (like, eq, neq, ls, gt, lse, gte, is_null, not_null, in, nin, pattern, or, and);
code - наименование поля, по которому будет производится фильтрация, например ShortName, Name, Code и т.д. Наименования полей можно увидеть в ответе на запрос, если выполнить запрос без ограничений;
value - значение кода поля, по которому будет производится фильтрация.
При формировании запроса необходимо указывать элемент массива для блока параметров conditions.

Пример запроса
http://nsi.eaeunion.org/api/v1/dictionaries?conditions[0].conditionType=like&conditions[0].code=%23code&conditions[0].value=205&offset=0&limit=100&dateActual=2024-06-07
где conditions[0].conditionType=like&conditions[0].code=%23code&conditions[0].value=205 - параметры фильтрации данных по условию "вхождения" (like) в код справочника значения 205

Сортировка
Для сортировки выдаваемого результата указываются значения параметров:

code - код поля, по которому будет производится сортировка, например ShortName, Name, Code и т.д. Наименования полей можно увидеть в ответе на запрос, если выполнить запрос без ограничений;
sortOrder - задается тип сортировки по возрастанию (asc) или убыванию (desс)
Пример запроса
http://nsi.eaeunion.org/api/v1/dictionaries?conditions[0].conditionType=like&conditions[0].code=%23code&conditions[0].value=205&offset=0&limit=100&dateActual=2024-06-07&code=%23code&sortOrder=asc
где code=%23code&sortOrder=asc - параметры сортировки по возрастанию значения кода справочника

Получение сведений об изменении объекта НСИ по НПА
GET
http://nsi.eaeunion.org/api/v1/dictionaries/{dictionaryCode}/npa/{npaId}
Метод позволяет получить перечень измененных записей объекта НСИ (справочника или классификатора) указанным в запросе НПА (учитывается НПА, регламентирующий начало и окончание действия элемента). Параметр	Тип	Обязательность	Описание
dictionaryCode	string	Да	Код справочника (классификатора), для которого требуется получить изменения
npaId	string	Да	Идентификатор НПА
