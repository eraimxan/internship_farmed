Все запросы начинаются с префиксов:

Для русского языка

http://taldau.stat.gov.kz/ru/

Для казахского языка

http://taldau.stat.gov.kz/kk/

Для английского

http://taldau.stat.gov.kz/en/

 

На текущий момент реализованы следующие виды запросов:

 











 

 

GetIndexTreeData
 

http://taldau.stat.gov.kz/ru/Api/GetIndexTreeData?p_measure_id=1&p_index_id=2709379&p_period_id=7&p_terms=741880&p_term_id=741880&p_dicIds=67&idx=0&parent_id=

где следует указать:

-       p_index_id - идентификатор показателя;

-       p_period_id - идентификатор типа периода;

-       p_terms - список элементов разделенных через запятую для выборки (termIds из GetSegmentList);

-       p_term_id - указывается один главный элемент по которому нужна детализация (один из p_terms);

-       p_dicIds - список справочников через запятую (dicId из GetSegmentList);

-       idx - индекс разрезности (idx из GetSegmentList);

-       parent_id - идентификатор родительского элемента. Для получения корневого элемента следует оставлять пустым.

GetPeriodList

где нужно указать:

         indexId - указывается идентификатор показателя.

GetIndexPeriods
 
http://taldau.stat.gov.kz/ru/Api/GetIndexPeriods?p_measure_id=1&p_index_id=2709379&p_period_id=7&p_terms=741880&p_term_id=741880&p_dicIds=67
 

где нужно указать:

-       p_index_id - идентификатор показателя;

-       p_period_id- идентификатор типа периода;

-       p_terms - список элементов разделенных через запятую для выборки (termIds из GetSegmentList);

-       p_term_id - указывается один главный элемент по которому нужна детализация (один из p_terms);

-       p_dicIds - список справочников через запятую (dicId из GetSegmentList).

Список элементов все 4-х полей совпадают и служат для кросс обращений друг к другу.

 

GetIndexAttributes
 

http://taldau.stat.gov.kz/ru/Api/GetIndexAttributes?periodId=7&measureID=1&measureKFC=1&indexId=2709379

 

где нужно указать:

-       indexId - указывается идентификатор показателя;

-       periodId - тип периода.

 

Ответ сервера возвращается в формате JSON.

{

"id":2709379,

"path":"/0/700894/700895/700911",

"decFormat":0,

"namePath":"Национальные счета/Текущие счета/Счет производства",

"name":"Валовой внутренний продукт методом производства",

"cgParams":"1,1,1,1",

"measureId":1,

"measureKfc":1,

"measureSign":"",

"measureName":"тенге",

"preferredMeasureId":1,

"preferredMeasureName":"тенге",

"preferredMeasureKfc":1,

"preferredMeasureSign":""

}

 

Описание полей ответа:

-       namePath - это иерархия родительских показателей до текущего показателя;

-       name - наименование показателя;

-       decFormat - указывает на точность количества знаков после запятой. -1 означает что точность не определена;

-       measure - это префикс для единиц измерения;

-       Id - идентификатор единицы измерения;

-       Name - наименование единицы измерения;

-       Kfc - множитель, коэфициент относительного корневой единицы измерения;

-       preferredMeasure - это префикс для единиц измерения по-умолчанию.


IndexFeed
http://taldau.stat.gov.kz/ru/Api/IndexFeed?pageType=Branch&periodID=8&termID=701156

где нужно указать:

-       periodID - тип периода из запроса Industry/GetPeriods;
